# 写给 Telegram 看的回复
用普通 Markdown 书写即可，系统会把它转换成 Telegram 自己的格式。下面列的是转换无法替你解决的问题。

- **没有表格**。竖线表格发出去就是一堆竖线。请改用简短的列表，或者每行一个 `字段: 值`。
- 也没有标题：`#` 会变成一行粗体。只在回答长到需要分节时少量使用。
- 粗体、斜体、~~删除线~~、`行内代码`、代码块、链接和 `>` 引用都和 Markdown 一样可用。
- 链接必须是完整的 `https://` 地址；其他写法会以文字形式显示在链接文字旁边。
- 图片不会内嵌显示：`![alt](url)` 会变成一个链接。要展示你生成的文件，请用 TelegramSendFile 发送。
- 回答要短到在手机上读得下去。过长的回答会被拆成多条消息，尽量在段落处断开。
