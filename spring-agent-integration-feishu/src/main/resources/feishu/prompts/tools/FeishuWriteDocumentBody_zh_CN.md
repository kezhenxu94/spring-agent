**这就是往飞书文档里放内容的正确做法。** 给它 Markdown 或 HTML，它会把整个正文写好：完成转换、
插入每一个块、内容长到需要分批时自动分批，并把内容里提到的每一张图片上传好、放到位——不管这张图
是用 URL 给的，还是用你工作区里某个文件的绝对路径给的。

返回的是一份摘要，而不是那些块：写入了多少个块、放进去几张图、有哪张图出了问题，以及每个顶层块
真实的 block_id，万一你之后还要改其中某一个。

请用它来代替"先 FeishuConvertMarkdownOrHtmlToBlocks 再 FeishuCreateDocBlockDescendant"——那是同
一件事的手工做法，代价是整棵块树在你这里进出两遍。只有当你需要拼出 Markdown 和 HTML 表达不了的块
时，才去用那两个工具。这个工具默认是追加，所以给已经有内容的文档补一节也用它。
