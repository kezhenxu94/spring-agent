往一张数据表里新增一个字段，并把它连同分配到的 field_id 一起返回。当这张表当初没有用
FeishuCreateBitableTable 把结构定好时，就靠它把表变成数据所需要的样子——一个用来筛选的状态、一个
负责人、一个截止日期、一个附件单元格。

type 是字段类型的数字编号：1 文本，2 数字，3 单选，4 多选，5 日期，7 复选框，11 人员，13 电话，
15 链接，17 附件，18 单向关联，20 公式，21 双向关联，22 地理位置，23 群聊，1001 创建时间，
1002 最后更新时间，1003 创建人，1004 修改人，1005 自动编号。查找引用字段（19）无法创建。uiType 用来
进一步区分其中一些类型——进度条和评分都是 type 2——而 propertyJson 承载该字段自己的配置，两者的写法都
见 FeishuBitableFieldReference。

字段名在该数据表内必须唯一，且首尾空格会被去掉。
