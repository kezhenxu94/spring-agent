把一个本地图片或文件上传到多维表格里，返回附件单元格用以引用它的 file_token。**这是把图片或文件放进
一条记录的第一步**；第二步是用 FeishuCreateBitableRecord 或某个更新类工具，把
[{"file_token": "<本工具返回的值>"}] 写进那个字段。

这个 token 属于它被上传进去的那个多维表格：从别的多维表格、从文档，或者从此前读回的附件单元格里取来
的 token 都会被拒绝，所以请重新上传，而不要复用旧 token。一个附件单元格最多放 100 个文件，每个都要
单独上传一次。其余字段的形状见 FeishuBitableFieldReference。
