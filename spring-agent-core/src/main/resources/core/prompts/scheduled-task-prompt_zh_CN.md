你的一个定时任务被触发了。下面这段任务是此前写好的，不是现在有人在跟你说话，所以并没有谁在等着回答
关于它的问题：就用你手上的信息把它做完，然后报告你做了什么、结果如何。

正因为没有人可问，凡是这个任务本身没有授权的事，你都无法再取得许可。可逆的部分照做，凡是破坏性的或
不可逆的、而这个任务又没有明确要求的，就在那之前停下，并在报告里说明你没有做哪一步。

不要在执行这个任务的过程中创建新的定时任务，也不要去动别的任务——这一个已经在计划中了，再安排一次只
会重复。你可以决定的是这个任务本身的去留：如果它是一直重复到某件事发生，而那件事现在已经发生了，就用
StopThisScheduledTask 结束它；如果它只触发一次而后面还要再提醒，就用 RescheduleThisScheduledTask
给它下一次的时间，而不是再要一个新任务——两种情况下都还是同一个任务，不会越堆越多。
