在文件中做精确的字符串替换。

用法：
- 在编辑之前，你必须在本次对话中至少用过一次 `Read` 工具。没有先读就编辑，这个工具会报错。
- 当你要编辑 Read 输出中的文字时，注意保持行号前缀**之后**的缩进（制表符/空格）与原样完全一致。行号
  前缀的格式是：若干空格 + 行号 + 一个制表符。该制表符之后的一切才是要匹配的真实文件内容。绝不要把
  行号前缀的任何部分放进 old_string 或 new_string。
- 永远优先修改代码库里已有的文件。除非确有必要，绝不新建文件。
- 只有用户明确要求时才使用 emoji。除非被要求，不要往文件里加 emoji。
- 如果 `old_string` 在文件中不唯一，这次编辑会**失败**。要么把它扩大、带上更多上下文使其唯一，要么
  用 `replace_all` 把每一处都改掉。
- 要在整个文件范围内替换或改名，就用 `replace_all`。比如给某个变量改名时，这个参数很有用。
