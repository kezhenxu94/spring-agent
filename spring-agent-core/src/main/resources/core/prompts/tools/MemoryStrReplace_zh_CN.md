在一个已存在的记忆文件里替换一段精确匹配的文字。

用法：
- 所有路径都相对于记忆库根目录。
- oldStr 必须完全匹配（包括空白和换行），并且在文件中只能出现一次。
- 如果 oldStr 出现多于一次，这次编辑会被拒绝 —— 请带上更多上下文来消除歧义。
- newStr 可以为空，表示删掉匹配到的文字。
- 返回被编辑处附近的一段内容，带行号。

常见用途：
- 更新某个记忆文件里已经过时的内容（改正文，同时更新 frontmatter 里的 description）。
- 记忆文件被改名、或其说明发生变化时，更新 MEMORY.md 索引。
- 删除记忆文件时，把它在 MEMORY.md 里的条目一并去掉（文件本身用 MemoryDelete 删）。
- 编辑过记忆内容之后，让 frontmatter 里的 name 和 description 与之保持一致。
