把某个已有记忆文件里的一段文字精确替换掉。

用法：
- 路径相对于你要编辑的那个记忆的根目录。不传 scope 就改**你自己的**记忆；刚读到的文件来自某个共享
  记忆时，要把那个 scope 写上。
- old_str 必须完全一致（含空白与换行），并且在文件中只出现一次。出现多于一次就会被拒绝：请多带上一
  些上下文，让它唯一。
- new_str 可以为空，表示把匹配到的文字删掉。

常见用途：
- 更新记忆文件里已经过时的内容，并同时更新 frontmatter 里的 description。
- 记忆改名或说明变化后，更新 MEMORY.md 里对应的那一行。
- 删除记忆文件之后，去掉它在 MEMORY.md 里的那一行。
