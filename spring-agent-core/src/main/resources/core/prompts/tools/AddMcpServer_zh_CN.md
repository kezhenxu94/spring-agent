为这个用户注册一台远程 MCP（Model Context Protocol）服务器，让它的工具能被智能体使用。仅支持远程的
streamable HTTP 服务器。本地/stdio 服务器（任何通过命令启动的）和 SSE 服务器都不支持。

URL 和连接会在保存前先做校验：如果 URL 不被允许、服务器连不上，或者它指向的是内网/回环地址，则什么
都不会存下来，并返回一个错误。请始终拿着你收到的 URL 去实际调用一次，而不要一看就拒绝——错误信息会
说明这个 URL 为什么不合法。成功后会返回该服务器的工具名称。用已存在的名称再添加一次，会覆盖它原来的
配置。

这台服务器提供的每个工具都会带上一个前缀暴露出来。如果用户说了工具该叫什么，就把 toolPrefix 一起
传上；不传的话前缀是服务器名称的哈希，能用，但看不出是什么。同一个用户能访问到的两台服务器不能用
同一个前缀。
