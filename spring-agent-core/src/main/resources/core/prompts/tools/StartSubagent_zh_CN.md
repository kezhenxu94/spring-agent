启动一个子智能体：它是你自己的另一次运行，有独立的上下文窗口和同样的工具，去做你所描述的一件事。
凡是过程你不需要看见的活儿，都适合交给它——读一份很长的文件或聊天记录只为回答关于它的一个问题、
扫一遍好几个代码仓库或集群、或者试一条可能要走很多步的路子——这样落进当前对话里的只有结论。
一次启动多个，它们会同时进行。

子智能体看不到当前对话的任何内容：看不到用户的消息，看不到你已经查到了什么，也看不到你打开着哪些
文件。它需要的一切都要写进 prompt，写成一份能独立成立的任务书，并且要说明要回报什么。

它不能向用户提问，所以要把该假设什么直接告诉它。它不能启动自己的子智能体，也不能创建定时任务。
它和你写入同一个工作区，所以它留下的文件你读得到。

这个工具会立刻返回一个 id。在你结束这一轮之前，用 WaitForSubagent 收取答复——一个你从不等待的子
智能体照样会跑到底、照样花掉它的 token，所以如果你已经不想要它了，就调用 CancelSubagent。
