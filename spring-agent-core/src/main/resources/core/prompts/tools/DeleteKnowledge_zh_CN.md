把一份文档及其所有分片从知识库里删除。

用法：
- docId 从 ListKnowledgeBase 获取。
- scope 是要从哪个知识库里删，ListKnowledgeBase 的每一行都会说明："own"、"group" 或
  "tenant"。文档 id 只在一个知识库内部唯一，跨知识库并不唯一——同一个文件或页面既私下存过、
  又按公司范围存过，就是两份文档共用一个 id——所以不填这个参数就无从判断这次删除指的是哪一份，
  而把它们全删掉，等于为了清理一份私人文档而丢掉一份共享文档。
- 只能删除当前用户能访问到的文档；属于其他用户的文档，或者不在你所指定的那个知识库里的 id，
  都会被报告为"未找到"。
- 该操作不可撤销。从群的知识库或公司的知识库里删除，是把它从所有人那里拿走，所以除非对方刚刚
  就要你这么做，否则先问过他们。
