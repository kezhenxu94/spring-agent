创建一个定时任务。周期任务要给一个六段式 Spring cron 表达式（秒 分 时 日 月 周）；例如
"0 0 1 * * MON" 是每周一 01:00，"0 */30 * * * *" 是每 30 分钟一次，"0 0 0 * * MON-FRI" 是工作日的
午夜。一次性任务要给 scheduledAt，是一个带时区偏移的 ISO-8601 时间戳，例如
"2025-01-15T10:00:00+08:00"。

凡是相对的说法（“明天早上”），先用 CurrentDateTime 换算成绝对时间，因为这里的时间都是绝对的。
cronExpression 和 scheduledAt 只能给其中一个，绝不能同时给。

要跑固定次数的任务（“每 10 分钟提醒我一次，提醒 10 次”），直接给 maxRuns，不要自己去算什么时候
该停：次数由调度器来记，是准的。
