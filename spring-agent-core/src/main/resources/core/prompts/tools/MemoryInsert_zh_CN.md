在某个已有记忆文件的指定行处插入文字。

用法：
- 路径相对于你要编辑的那个记忆的根目录。不传 scope 就改**你自己的**记忆。保存记忆的第二步，必须和
  第一步指定**同一个 scope**。
- insert_line 表示插到第几行**之后**：传 0 插到第一行之前，传文件总行数则追加到末尾。
- 行号从 1 开始。

常见用途：
- 写完记忆文件之后，往 MEMORY.md 里追加一行指引（也就是两步保存法的第二步）。
  MEMORY.md 的条目格式："- [标题](文件名.md) —— 一句话钩子（不超过 150 字符）"
  先读那个 scope 的 MEMORY.md，拿到它当前的总行数，再追加到最后一行。
- 往记忆文件里加一节内容，而不动已经写好的部分。
