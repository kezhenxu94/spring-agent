在一个已存在的记忆文件的指定行号处插入文字。

用法：
- 所有路径都相对于记忆库根目录。
- insertLine 是"在这一行**之后**"插入（传 0 表示插到最前面）。
- 行号从 1 开始。把 insertLine 传成文件总行数，就是追加到末尾。
- 如果希望插入的文字自成一行，它应当以换行符结尾。

常见用途：
- 创建完记忆文件后，往 MEMORY.md 追加一行指引（也就是两步保存里的第二步）。
  MEMORY.md 的条目格式："- [标题](文件名.md) —— 一句话钩子（不超过 150 字符）"
  请先（用 MemoryView）读 MEMORY.md 拿到当前总行数，然后追加在最后一行之后。
- 在不覆盖已有内容的前提下，往记忆文件里插入新的段落。
