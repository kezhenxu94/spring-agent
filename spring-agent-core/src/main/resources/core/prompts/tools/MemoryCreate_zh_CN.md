新建一个记忆文件。

用法：
- 路径相对于你要写入的那个记忆的根目录。不传 scope 就写进**你自己的**记忆；要写到别人也会读到的地
  方，就明确指定 scope。
- 该文件必须**尚不存在**；要改已有的，请用 MemoryStrReplace。
- 保存一条记忆是**两步**：
    第一步 —— 调用 MemoryCreate，按下面的 frontmatter 格式写出记忆文件。
    第二步 —— 调用 MemoryInsert，往**同一个 scope 的** MEMORY.md 里加一行指引。
            MEMORY.md 的条目格式："- [标题](文件名.md) —— 一句话钩子（不超过 150 字符）"
  每个记忆都有自己的 MEMORY.md，所以索引行加错了地方，读那份索引的人就找不到那个文件。
- 动手前先用 MemoryView 看索引，以免存下已经有的东西。
- **不要**保存：代码写法、git 历史、修复配方、项目自己的文件里已经写明的内容，以及只对当次有意义的
  状态。

该写进哪个记忆：
- own —— 这个人是什么样、偏好什么、希望你怎样跟他配合。一个人自己的偏好，绝不放到别人能读的地方。
- group —— 对这个群聊有约束力的决定、约定或事实，也就是这个群里的下一次对话理应一开始就知道的东西。
  群聊里还有别人，所以写进去的东西他们都会读到。
- tenant —— 对整个公司都成立，而不只是对某个人或某个团队成立。

往共享记忆里写，意味着所有共享它的人在自己的对话里都会把它当成事实，而且写入途中没有任何人复核。所
以只把那些在它所影响的人面前说过的内容存进去，并在记忆里写明是谁告诉你的、在哪次对话里说的。

记忆文件的 frontmatter 格式：
  ---
  name: <简短名称>
  description: <一句话说明，用于在以后的对话里判断它是否相关>
  type: <user | feedback | project | reference>
  ---
  <记忆内容>

对 feedback 和 project 这两类，正文按这样组织：
  <规则或事实>
  **Why:** <原因 —— 过去发生过的事、约束，或偏好>
  **How to apply:** <什么情况下适用>
