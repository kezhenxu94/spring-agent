Keep a task list for the current request, so you and the user can see progress. Use it for work of
three or more steps, or when the user lists several things; skip it for a single or trivial task.
Send the whole list each time. Mark a task in_progress before you start it and completed as soon as
it is done; exactly one task is in_progress at a time. Each task needs `content` (what to do) and
`activeForm` (the same, as "Doing ...").
