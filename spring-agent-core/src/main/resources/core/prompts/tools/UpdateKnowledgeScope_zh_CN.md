把一份文档移到另一个知识库：只留给自己、共享给当前这个群，或者共享给整个公司。

用法：
- docId 从 ListKnowledgeBase 获取。
- from 是它现在在哪个知识库里，ListKnowledgeBase 的每一行都会说明："own"、"group" 或
  "tenant"。文档 id 只在一个知识库内部唯一，跨知识库并不唯一，所以同一个文件或页面存过两次，
  就是两份文档共用一个 id——不填这个参数，被移走的就可能是不该动的那一份。不在你所指定的那个
  知识库里的 id，会被报告为"未找到"。
- to 是它应该去的地方："own"、"group" 或 "tenant"。
- 该文档的 id、标题、来源和内容都保持不变；改变的只是谁能读它。要改文档**说了什么**，请用
  IndexKnowledge 以同一个 id 再存一次。
- 把某样东西共享给一个群、或者共享给整个公司，这是存下它的那个人的决定，不是你的决定。除非对方刚刚
  就要你这么做，否则在扩大一份文档的可见范围之前先问过他们。
