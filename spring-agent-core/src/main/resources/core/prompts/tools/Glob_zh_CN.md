按文件名找文件，返回每个文件的绝对路径，最近改动过的排在前面。

pattern 是一个 glob：`**/*.md` 匹配任意层级下的所有 Markdown 文件，`SKILL.md` 匹配任何位置上的这个
文件名，`skills/*/SKILL.md` 只往下看一层。不带 `**` 的模式同样会在任意层级上匹配，所以 `*.java` 也
能找到子目录里的 Java 文件。

搜索范围被限定在这次会话够得着的几个 home 目录内——你自己的，以及在有的情况下这个群的和这个租户的，
它们都已在你的指令里列出。不填 path 就搜你自己的 home。超出这些目录的路径会被直接拒绝，而不是去搜：
这台机器上你能这样看的，就只有这些。

`.git`、`node_modules`、`target`、`build`、`dist`、`.idea`、`.vscode`、`__pycache__` 会被跳过。

当你知道文件叫什么、或者它按约定应该叫什么，但不知道它在哪里时，用这个工具。如果你知道的是文件里写
了什么，那就用 Grep。拿到路径之后再用 Read 去读——路径不是内容，这个工具不会告诉你文件里写了什么。

一次回复里调用好几次是没问题的，而且这才是省事的搜法：与其分三轮把一个模式一点点收窄，不如一次就把
两三个猜测一起试掉。
