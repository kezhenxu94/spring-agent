查看持久记忆库里某个文件的内容，或者列出某个目录的内容。

用法：
- 如果 path 指向目录：列出两层深度，并显示各文件大小。
- 如果 path 指向文件：返回其内容，带行号。
- 所有路径都相对于记忆库根目录。
- path 传空字符串或 "/" 可查看根目录，那会列出全部记忆文件。
- 请先查看 "MEMORY.md" —— 它是始终会被载入的记忆索引，在读写任何记忆之前都该先看它。
- 查看文件时可以另外给一个行区间 'start,end'，用来分段翻阅很长的文件。

记忆文件的结构：每个记忆文件都用 YAML frontmatter：
  ---
  name: <简短名称>
  description: <一句话说明，用于在以后的对话里判断它是否相关>
  type: <user | feedback | project | reference>
  ---
  <记忆内容>

记忆的类型：
- user      —— 用户的角色、目标、专长、偏好
- feedback  —— 关于该怎么做事的指导（既包括纠正，也包括已被确认可行的做法）
- project   —— 正在进行的工作、决定、期限，且无法从代码或 git 推断出来
- reference —— 指向外部系统的线索（Linear 项目、看板、频道等）
