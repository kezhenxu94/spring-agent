在同一个记忆内重命名或移动文件。

用法：
- 两个路径都相对于**同一个**记忆的根目录；重命名不会把记忆从一个记忆挪到另一个去。
- 源路径必须存在，目标路径必须不存在。
- 改完之后，用 MemoryStrReplace 更新它在该 scope 的 MEMORY.md 里的链接。

要把一条记忆挪到别人也会读的记忆里去，请分四步明确地做：用 MemoryView 读出该文件，用 MemoryCreate
在你想要的那个 scope 里建出来，用 MemoryInsert 把它的索引行加进**那个** scope 的 MEMORY.md，最后用
MemoryDelete 删掉你自己的那一份。让更多人能读到某样东西，和整理一个文件名是两件不同的事，而且上面
每一步都可能被单独拒绝。
