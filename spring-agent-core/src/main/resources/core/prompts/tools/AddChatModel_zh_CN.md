为这个用户注册一个 OpenAI 兼容的对话模型，让他们的对话由它来回答，而不是应用自带的模型。需要提供一个
便于称呼的名称、接入地址、该端点所使用的模型名，以及一个 API 令牌。

保存前会先测试这个端点：如果连不上、令牌被拒绝，或者模型名不被识别，则什么都不会保存，并返回错误信息。
注册本身不会切换模型——切换请调用 UseChatModel，或让用户输入 /config <名称>。用已存在的名称再注册一次，
会就地更新它。

思考强度是可选的，且只能取列出的那几个值；不填就沿用应用自己配置的强度。之后若要单独改它、又不想再
提供一次令牌，可以在 /config 表单上改，或者输入 /config <名称> <强度>。

令牌会加密存储，之后不会再展示，连设置它的用户本人也看不到。
