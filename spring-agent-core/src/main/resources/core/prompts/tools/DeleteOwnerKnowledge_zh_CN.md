把一份文档及其所有分片，从另一个身份自己的知识库里删除。仅管理员可用。

用来清理那些没有人会登录进去的身份名下存着的东西——比如某个已经不存在的事件源的 playbook，
或者新的一份没有覆盖掉、而是另存了一份的旧副本。别人删不掉它：它的 owner 不是人，而写下它的
管理员又不是那个身份。

用法：
- owner 就是用户 id，可以用 ListPlaybooks 查看；docId 从 ListOwnerKnowledgeBase 获取。
- 只会动这个身份自己的知识库；不在里面的 id 会被报告为"未找到"，而不会去别处删。
- 该操作不可撤销，而且这里的文档正是自动巡检的依据。除非对方刚刚就要你这么做，否则先问过他们。
