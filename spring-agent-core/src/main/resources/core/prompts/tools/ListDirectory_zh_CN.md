列出一个目录里有什么：先是子目录，然后是文件，每一项都标明是哪一种，名字相对于你问的那个目录。

depth 是往下看几层——默认 1，只看直接子项；limit 限制返回多少条，默认 50。到了上限时回复里会说明，
那是提醒你换一个更窄的路径再问一次，而不是可以认为你已经看全了。

列出的范围被限定在这次会话够得着的几个 home 目录内——你自己的，以及在有的情况下这个群的和这个租户
的，它们都已在你的指令里列出。不填 path 就列你自己的 home。超出这些目录的路径会被直接拒绝。

`.git`、`node_modules`、`target`、`build`、`dist`、`.idea`、`.vscode`、`__pycache__` 会被跳过。

用它来摸清一个你没见过的目录：装了哪些技能、某个技能的文件夹里有什么、工作目录里被写进了什么。如果
你已经知道要找的名字，那就用 Glob——一层一层地列，是找它最慢的办法。
