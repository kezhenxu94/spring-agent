从本地文件系统读取一个文件。你可以用这个工具直接访问任何文件。假定它能读取本机上的所有文件；如果
用户给出了某个文件的路径，就假定该路径有效。读一个不存在的文件也没关系，那会返回一个错误。

用法：
- filePath 参数必须是绝对路径，不能是相对路径。
- 默认从文件开头起最多读 2000 行。
- 你可以另外指定起始行 offset 和行数 limit（对很长的文件尤其有用），但更推荐不传这两个参数、直接
  把整个文件读下来。
- 超过 2000 个字符的行会被截断。
- 结果以 cat -n 的格式返回，行号从 1 开始。
- 这个工具可以读取图像（PNG、JPG 等）。读取图像文件时，其内容会以视觉形式呈现。
- 它可以读取 PDF 文件（.pdf），按页处理，同时提取文字和视觉内容以供分析。
- 它可以读取 Jupyter notebook（.ipynb），返回全部单元格及其输出，代码、文字和图表一并给出。
- 它只能读文件，不能读目录。要看一个目录，请通过 Bash 工具执行 ls。
- 你可以在一次回复里调用多个工具。预判性地并行读取多个可能有用的文件，总是更好的做法。
- 你会经常被要求查看截图。如果用户给出了截图路径，一定要用这个工具去看该路径下的文件；它对所有临时
  文件路径都有效。
- 如果你读到的文件确实存在但内容为空，你会收到一条系统提醒来代替文件内容。
