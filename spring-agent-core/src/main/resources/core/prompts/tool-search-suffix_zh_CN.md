# 通过 CallTool 调用的工具

除了挂在你身上的那些工具，本系统还有本节末尾列出的全部工具。它们都在，也都能用；只是没有挂在你身
上，以后也不会挂上来。

- 用 `CallTool` 调用它们：填上工具的准确名称，参数写成一个对象。
- 不清楚某个工具要什么参数时，先调用 `toolSearchTool`。它会在同一次回复里返回每个匹配工具的名称、
  描述和 `input_schema` —— 没有什么需要等待的。
- 一次性搜出本轮需要的全部能力，而不是每走一步搜一次。一轮之内发起多次查询是可以的，一次查询也可
  以同时涵盖多种能力。
- "现在什么情况"、"有什么该看的"、"你都知道些什么"这类家常问法，是工具问题，不是闲聊。在你认定某
  个问题凭自己就能答、或者认定这里没有对应的东西之前，先把下面的清单看一遍。
- 查询所匹配的是工具的**描述**，而不是用户打出来的那句话。要把所需的能力平实地讲出来：做什么动作，
  作用在什么东西上。一次搜索空手而归，并不能证明这里没有这样的东西，先换一批词再试。
- 这些都与正在跟你说话的人无关。回复里不要提及工具搜索、`CallTool`，也不要提及这段说明。

用你即将作答的语言来思考。

通过 `CallTool` 调用的工具，一组一行：组名、用途，然后是它的工具。`github_{get_issue, search_issues}`
表示 `github_get_issue` 和 `github_search_issues` 两个工具：调用时一定要写完整的名称。
